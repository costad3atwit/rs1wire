  CrcMismatch, ReadFailed,
  PowerOnReset, or Parse

@startuml
hide empty description
skinparam monochrome true
skinparam shadowing false
skinparam defaultFontSize 10

state "Idle (0)" as Idle
state "InProgress (-1)" as IP
state "CompleteUnread (1)" as CU

[*] --> Idle : w1 driver loaded
Idle --> IP : trigger
IP --> CU : conversion done
CU --> IP : trigger\n(replaces results)
CU --> Idle : all sensors read\nor discarded

note right of Idle
  Sensor::read():
  0  -> fresh conversion
  1  -> Err BulkPending
  -1 -> Err ConversionInProgress
end note

note right of IP
  bulk_convert() blocks through -1
  (synchronous trigger write);
  seen only by other callers.
  bulk_convert() in -1:
  Err ConversionInProgress
end note
@enduml
